# 淘灵热 — 修仙世界商业模拟游戏

## 游戏概述

**淘灵热**是一个基于文字的修仙世界商业模拟游戏。玩家扮演一名底层修仙者，在灵石矿发现引发的人口涌入和物价波动中寻找商机，通过交易积累资源，最终实现修仙飞升。

---

## 背景设定

### 世界观

在一个传统的修仙世界中，某地突然发现了一座大型灵石矿。这一发现迅速引发了连锁反应：

1. **人口涌入**：大量修仙者和修仙商贩聚集到该地区
2. **物价波动**：灵石、丹药、法器、材料的价格开始剧烈变化
3. **机会涌现**：有人暴富，有人破产，底层修仙者的命运在此分野

### 玩家身份

你是一名出身贫寒的底层修仙者：
- 炼气期修为，资质平平
- 灵石匮乏，生活拮据
- 没有背景，无人依靠
- 但你有敏锐的商业嗅觉和坚定的道心

---

## 核心机制

### 1. 物价系统

#### 影响因素

- **新闻事件**：灵石矿产量变化、官方政策、突发事件
- **供需关系**：修仙者数量变化、材料稀缺程度
- **时间流逝**：节日、季节、修仙周期
- **谣言传播**：真假消息引发的市场恐慌或盲目追涨

#### 商品类别

| 类别 | 代表商品 | 波动性 |
|------|----------|--------|
| 基础材料 | 灵石、玄铁、兽骨 | 中等 |
| 丹药 | 筑基丹、聚气丹、疗伤药 | 高 |
| 法器 | 飞剑、护盾、法袍 | 极高 |
| 功法 | 秘法残卷、传承 | 极高 |
| 稀有资源 | 天材地宝、妖丹 | 波动极大 |

---

### 2. 交易系统

#### 交易方式

- **市场交易**：公开市场，价格透明，风险较低
- **黑市交易**：价格波动大，风险高，但可能捡漏
- **私人交易**：与特定修仙者交易，建立人脉
- **拍卖行**：稀有物品竞拍，心理战

#### 策略要素

- **囤积**：低价买入，等待涨价
- **快进快出**：抓住短期波动
- **分散投资**：不把鸡蛋放在一个篮子里
- **情报收集**：提前预判价格走向
- **关系经营**：获得独家消息和优惠

---

### 3. 修仙系统

#### 境界划分

1. **炼气期**（初始）：灵力稀薄，主要靠商业积累资源
2. **筑基期**：需要大量灵石和丹药，投资风险与回报并存
3. **金丹期**：可以开辟洞府，建立商业网络
4. **元婴期**：飞升前夕，需要准备天材地宝

#### 资源用途

- **灵石**：购买功法、法器、丹药
- **丹药**：提升修为、疗伤、突破瓶颈
- **法器**：增强战斗力、提高收集效率
- **功法**：提升资质、获得新能力

#### 飞升条件

- 境界达到元婴大圆满
- 收集齐飞升所需的天材地宝
- 修仙心得圆满（游戏剧情达成）
- 灵石储备充足（如需要缴纳飞升费用）

---

### 4. 事件系统

#### 时间事件

- 事件以天、月、年为单位推进
- 每个时间点可能触发随机事件
- 玩家可以选择加速时间（跳过平淡期）

#### 事件类型

| 类型 | 描述 | 影响 |
|------|------|------|
| **新闻** | 灵石矿产量报告、官方公告 | 引发价格趋势变化 |
| **突发事件** | 矿难、妖兽袭击、门派冲突 | 短期剧烈波动 |
| **日常事件**：机遇与挑战 | 商业机密、仇家、贵人 | 个人资产/关系变化 |

---

### 5. 人脉系统

#### NPC 关系

- **矿工**：获取灵石矿内幕消息
- **商人**：获得交易优惠和市场情报
- **修仙者**：建立人脉，获得资源支持
- **门派弟子**：进入门派，获得庇护和资源
- **黑市商人**：获取稀有物品，但有风险

#### 关系作用

- **消息获取**：提前知道价格变动信息
- **交易优惠**：获得折扣或优先购买权
- **资源支持**：借贷物资、寻求庇护
- **商业合作**：合伙投资、共享信息

## 游戏流程

### 启动阶段

1. 初始化玩家属性（炼气期、初始灵石）
2. 介绍世界观和游戏目标
3. 提供初始选择（地区、身份特征）

### 主循环

每轮交互包含以下步骤：

1. **时间推进**：进入下一个时间点
2. **生成事件**：根据时间触发随机事件
3. **更新价格**：根据事件和市场规则调整商品价格
4. **展示状态**：显示当前时间、玩家资产、价格变化
5. **玩家决策**：提供选项让玩家选择行动

### 可选行动

| 行动 | 描述 |
|------|------|
| 查看市场 | 查看所有商品当前价格和历史趋势 |
| 购买物品 | 花费灵石购买商品 |
| 出售物品 | 出售库存商品获得灵石 |
| 查看新闻 | 查看近期新闻事件 |
| 查看库存 | 查看当前库存情况 |
| 查看人脉 | 查看已建立的关系和可用的NPC |
| 修行提升 | 消耗资源提升修为 |
| 加速时间 | 跳过一段时间（等待价格变化） |
| 游历探索 | 寻找机会和人脉（有风险） |

### 结局判定

游戏结束条件：

1. **飞升成功**：达成所有飞升条件 → **完美结局**
2. **破产**：灵石为负且无法恢复 → **失败结局**
3. **寿元耗尽**：修仙者寿命耗尽 → **平庸结局**
4. **主动退出**：玩家选择结束游戏 → **保存进度**
