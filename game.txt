# 修仙世界观设定

## 世界观概述
这是一个东方玄幻修仙世界，天地间灵气充裕，修炼者可突破凡躯，追求长生之道。

## 修炼体系

### 九大境界
1. **炼气期** - 感应天地灵气，打通经脉
2. **筑基期** - 筑大道之基，寿元翻倍
3. **金丹期** - 凝结金丹，御空飞行
4. **元婴期** - 元婴出窍，神识外放
5. **化神期** - 元神化形，沟通天地
6. **炼虚期** - 炼化虚空，瞬移千里
7. **合体期** - 肉身与元婴融合
8. **大乘期** - 飞升在即，渡天劫
9. **渡劫期** - 九重天劫，成仙或陨落

### 属性系统
- **修为**：修炼进度，决定境界提升
- **寿元**：活着的时间，每个境界增加上限
- **灵石**：通用货币，购买丹药、功法、装备
- **体力**：每次行动消耗，恢复方式：休息、丹药
- **攻击**：战斗能力
- **防御**：减免伤害
- **灵根**：影响修炼速度和功法契合度（金木水火土）
- **气运**：随机事件品质，奇遇概率

### 灵根类型
| 灵根 | 特点 |
|------|------|
| 金 | 攻击+20%，修炼速度正常 |
| 木 | 恢复+30%，防御+10% |
| 水 | 法术威力+25%，灵石消耗-15% |
| 火 | 攻击+25%，灵石获取+10% |
| 土 | 防御+20%，体力消耗-15% |
| 变异（双灵根） | 双属性加成，修炼速度-10% |
| 天灵根（全属性） | 全属性+15%，修炼速度+20% |

## 世界地理

### 主要势力
- **天剑宗**：剑修门派，攻击著称
- **玄丹门**：丹修门派，炼药专精
- **灵兽谷**：御兽门派，与灵兽契约
- **鬼灵宗**：鬼修门派，诡异莫测
- **散修联盟**：无门派修士聚集地

### 修炼地点
- **灵气洞府**：修炼速度+50%，需灵石租赁
- **炼丹房**：可炼制丹药
- **藏经阁**：可学习功法
- **坊市**：交易市场
- **秘境**：探险区域，机遇与危险并存

## 资源与物品

### 丹药
| 丹药 | 效果 | 价格 |
|------|------|------|
| 聚气丹 | 恢复100修为 | 10灵石 |
| 回春丹 | 恢复50体力 | 15灵石 |
| 筑基丹 | 筑基成功率+30% | 500灵石 |
| 金丹丹 | 金丹成功率+25% | 5000灵石 |

### 功法等级
- 黄阶（普通）→ 玄阶（稀有）→ 地阶（史诗）→ 天阶（传说）

## 时间系统
- 游戏时间以"天"为单位
- 每次行动消耗1天
- 寿元耗尽则游戏结束

## 事件类型
1. **修炼事件** - 提升修为
2. **奇遇事件** - 随机奖励/惩罚
3. **战斗事件** - 遭遇敌人
4. **资源事件** - 获得灵石/物品
5. **剧情事件** - 推动主线

---

## 游戏目标
- **胜利条件**：达到渡劫期并成功飞升
- **失败条件**：寿元耗尽、战斗中陨落、走火入魔
